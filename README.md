# WEBSTER — Unified Personal Assistant

This is the consolidated WEBSTER build based on architecture patterns audited from PersonalJarvis, OpenJarvis, NOVA, Siddharth Jarvis, Basir Jarvis, Browser Use, LangGraph-style stateful loops, and FaithMakes/Mark XXXIX.

Included: Bindu red orb UI, text input, microphone hook, provider abstraction, persistent local memory, student data model, web/search/open tools, risk classification, conversation/activity logs, .env secrets, and Windows installer/desktop shortcut.

FaithMakes/Mark XXXIX is CC BY-NC 4.0. WEBSTER does not copy its source; it uses compatible ideas only.

Camera, microphone, terminal, external communication and destructive operations remain permission-gated.

Run: copy .env.example to .env, add GEMINI_API_KEY, then run main.py.
